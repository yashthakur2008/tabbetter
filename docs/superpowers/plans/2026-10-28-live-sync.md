# Automatic tournament sync implementation plan

> **For agentic workers:** Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Keep an open tournament current from published Tabroom exports automatically, with no manual record uploads.

**Architecture:** A small injectable sync controller in `web/app.js` owns cadence, in-flight guarding, failure backoff and freshness state. `loadTournament` gains a background mode that refreshes data without clearing the view or filters. Pure fingerprint helpers describe meaningful pairing changes.

**Tech Stack:** Dependency-free browser JavaScript, Node 22 `node:test` with `node:vm` harnesses.

**Spec:** `docs/superpowers/specs/2026-10-28-tournament-intelligence.md`

## Global Constraints
- Node.js 22 or newer, no runtime dependencies.
- Public published exports only; server cache for tournaments is 300000 ms.
- Preserve existing routes, filters, member records and accessibility.
- Preserve the uncommitted redesign edits in `web/app.js`, `web/index.html`, `web/styles.css`, `tests/redesign.test.mjs`.
