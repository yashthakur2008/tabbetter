# Security reporting

Please do not publish credentials, private ballots, student contact details or exploit payloads in public issues. Use GitHub's private vulnerability reporting feature for sensitive reports when enabled; otherwise contact the maintainer through the repository profile to arrange a private channel.

TabBetter is an independent companion. Problems with Tabroom accounts or its service belong with https://www.tabroom.com/index/help.mhtml.

Review focus includes upstream-host restrictions, publication boundaries, minimal exported fields, browser text escaping, source freshness and repository credential hygiene.
